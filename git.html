GitHub & Git

Differences

GitHub - a cloud-based platform where you can store and share your work with others

Git - a version control system that increases the workflow and tracks changes in the work

Set up


      git config --global user.name "[Name]"
      git config --global user.email "[email@example.com]"
      git config --list
        

      ls -al ~/.ssh
      ssh-keygen -t ed25519 -C "your-email@example.com"
      cat ~/.ssh/id_ed25519.pub
      ssh -T git@github.com
